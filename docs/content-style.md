# 课程与速查编写规范

## 资料与适用范围

- 以手册确认芯片行为和限制。每节从实际项目里的判断出发，说明为什么这样选、换个条件会怎样、怎样用读回值或测量证实。把手册事实、计算推导和实验设计讲清楚。
- 每个实验至少提供一个可复现的故障。给出先看什么、读到不同结果时去哪里查、修复后如何验证。课后题要求解释因果或迁移到新条件。
- 外设寄存器以中文 RM0008 为主要参考，中文固件函数库手册用于核对寄存器与库调用的对应关系、函数参数和描述。涉及版本差异时，用项目的 SPL 源码和头文件核对实际行为。涉及封装引脚、电气特性、频率限制等型号特性时，再链接到中文数据手册的对应页。
- 原理图、结构图和时序图从中文手册截图，标出该版本的图号，提供原图与中文 PDF 页码直达。按图中的器件与信号方向讲解，再对应到配置和板上现象。

## 课程顺序

1. 先解释外设是什么、能解决什么问题和常见用途。用一个可观察的任务引入。
2. 用最小 SPL 示例讲清时钟、引脚、参数、初始化顺序和预期现象。内核功能用 CMSIS。示例注明运行前提，给出一个可改参数和检查点。
3. 用同一场景对照库函数、寄存器和位段，再沿中文手册原图解释信号路径。进阶模式放在基础例子之后，给出适用条件和验证方法。

## 项目顺序

1. 先给任务、接线约束和验收用例。引导使用者拆功能、选外设、检查引脚冲突、估算时序。
2. 列出各功能所需的 SPL／CMSIS 调用和对应寄存器位段，说明用到它们的原因。
3. 按依赖顺序拆成可单独验证的小步骤。每一步写明要做什么、读什么或测什么，以及未达到预期时怎么查。
4. 完成步骤与故障挑战后，在最后提供可展开的参考答案，包含资源分配、关键代码和可构建的完整参考源码入口。

## 寄存器

1. 先用一句话说明用途，再给出适用实例、偏移、复位值和访问属性。
2. 重复字段用紧凑的位图展示，保留位号、字段名、搜索和直达链接。相同编码集中解释一次。存在依赖关系时按实际配置顺序拆开。例如先判断 `MODE = 00`（输入）或 `MODE > 00`（输出），各自列出 `CNF` 的四个取值，输出再列出 `MODE` 的速度档位。
3. **紧接每个寄存器给一段最小 C 示例。** 写清目标、配置前提、如何定位位段、掩码或移位怎么来，以及预期读回值或板上现象。直接操作寄存器时遵守读写规则并保留无关位。示例涉及硬件差异时写清接线或有效电平。
4. 对容易混淆的配置给出正例和对应依据。例如 `CRL` 用 PA1 演示位 `[7:4]`，`CRH` 用 PC13 演示位 `[23:20]`，让读者能按相同方法推导其他引脚。
5. 可写字段提供「写入效果」入口，列出有效值、产生的效果和写入前提。区分普通读写、写 1 清除、写 1 置位等访问规则。重复字段可以共享编码。字段定义使用稳定锚点，课程、实验及相关条目中的用法链接到对应定义。
6. 只读字段说明由谁更新、何时变化。涉及预装载或写入受限时，写清何时写入、何时生效，并给出读回、计数或波形的验证方法及首个排故检查点。

## 标准库函数

1. 先用一句话说明用途，再按「参数、返回值、调用前提、行为」排列。每行标签和值顶端对齐，值换行后留在同一列。对照 SPL V3.5.0，解释参数和实际使用的结构体成员，列出实际读写的寄存器并链接到已有条目。
2. **紧接每个适用函数给一段最小 C 调用示例。** 指定实际外设或引脚、参数值及预期结果。同一个操作已有寄存器示例时，优先复用相同场景并互链。
3. 片段可按条目写明的前提独立使用。会复位整个端口、锁定引脚配置或覆盖整组位时，要在示例旁说明影响。该型号不支持的 API 标出适用范围和如何判断，省去不可运行的调用。
4. 说明函数何时调用、会触发什么、调用后还需做什么。示例给出可观察结果和首个排故检查点。

## 页面验收

- 使用技术手册风格，正文、图注、位图和代码保持清晰的层次。避免重复长表。桌面和手机都检查说明行对齐、表格可读性与横向溢出。
- 确认搜索、寄存器和位段直达、函数与寄存器互链、原图打开、课后题折叠。核对示例的位号和参数，并用项目工具链编译片段。
