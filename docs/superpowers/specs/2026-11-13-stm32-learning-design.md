# STM32F103C8T6 学习站需求与设计

课程、速查条目和页面按 [课程与速查编写规范](../../content-style.md) 实施和验收。

## 使用者与学习目标

使用者熟悉 C，正在用 STM32F103C8T6 跟视频学习，已经接触 GPIO 的寄存器写法和标准外设库（SPL），习惯在纸上记笔记。查寄存器位段、对照库函数定义和理解外设内部结构耗时较长。学习站要让这些材料能就地查阅，并帮助使用者从跟着示例配置外设，过渡到独立完成一个裸机项目。

裸机课程覆盖 STM32F103C8T6 的全部片上外设和项目必需的系统功能。学习者要能根据需求选外设，核对引脚、时钟和资源约束，设计状态和初始化顺序，上板测试并定位故障。验收允许查站内资料和纸质笔记，使用者自行完成设计和代码，并能解释关键配置。课程交付与学习验收分别检查：课程按芯片资源清单逐项核对，学习验收由单模块实验和综合项目共同组成。

## 核心体验

| 入口 | 必须支持的操作 |
| --- | --- |
| 学习 | 按依赖顺序学习下表中的全部模块。每个知识点给出实际问题、原理或信号路径、相关配置和约三道自测题。 |
| 速查 | 用寄存器名、位段名、SPL 函数名或中文关键词找到条目。从函数能跳到相关寄存器和位段，从配置能返回原理或实验。 |
| 项目 | 看任务、硬件前提、预期现象和验收条件，按需展开分级提示。综合项目保留需求和验收清单，使用者自行拆分功能。 |

课程优先使用官方手册中对应的原理图、结构图或时序图截图，标注图号和出处，并顺着图中的信号路径讲解。GPIO 使用 RM0008 图 13，说明输入缓冲、上下拉、推挽和开漏。课程解释 CPU 系统时钟和外设时钟使能的关系，示例从板上可验证的现象出发。

速查条目以稳定标识互链。寄存器页包含用途、偏移、复位值、访问规则、位段和取值。重复排列的字段用位布局展示，编码规则集中说明，具体位段仍可搜索和直达。SPL 页按外设列出公开函数，包含用途、参数、返回值、调用前提及读写的寄存器，常用函数补源码解读。芯片范围固定为 STM32F103C8T6。样章覆盖适用的 GPIO 寄存器和 GPIO 自身的公开函数，并收录实验涉及的 RCC 时钟使能条目。AFIO 重映射函数随相关课程讲解。

题目练习解释原理、阅读配置和定位故障。答案按需展开，包含答题要点、追问和相关知识链接。近两年公开面经或笔试回忆按可核实的日期、原帖和来源类型标注，题干按课程考点改编。缺少可核实出处的考点使用原创练习。解析以芯片手册和所用 SPL 源码为准。阶段项目按验收清单自评。

## 全芯片覆盖清单

覆盖以 STM32F103x8B 中文数据手册的设备特性、系统框图和 LQFP48 引脚表为准，结合中文参考手册的型号适用条件、内核资料和芯片版本相关勘误。相同类型的多个实例可以共用一课，但要列出每个实例在此型号上的引脚、时钟、IRQ、DMA 映射及功能差异，适用时给出冲突示例。课程发布前逐项核对该型号支持的工作模式和相关寄存器块。对其他 STM32F1 型号才有的资源，例如 DAC、SDIO、FSMC、I²S 和 USB OTG，标注适用性，供选型时核对。

| 模块 | 学习范围和验证任务 |
| --- | --- |
| RCC 与系统基础 | 时钟源、PLL、AHB/APB 分频、时钟门控、复位原因、时钟安全和 MCO。画出时钟树并核对总线频率及外设时钟。 |
| GPIO、AFIO、EXTI | GPIO 输入输出电路、引脚复用与重映射、外部和内部事件线、触发与挂起。上板做按键与 LED，验证边沿、消抖和引脚冲突。 |
| Cortex-M3 与调试 | 启动与向量表、NVIC 优先级和抢占、SysTick、SCB 与异常、SWD/JTAG、DBGMCU。通过单步、寄存器窗口和断点定位预设故障，验证调试暂停对外设的影响。 |
| 定时器 | TIM1 和 TIM2/3/4，计数、更新、输入捕获、输出比较、PWM、单脉冲、编码器、主从触发。另讲 TIM1 的互补输出、死区和刹车，用低压逻辑波形验证。 |
| USART | USART1/2/3，帧格式、波特率、收发时序、轮询/中断/DMA、错误与空闲检测，并说明同步、单线半双工、RTS/CTS、LIN、IrDA 和智能卡模式的适用条件。用串口记录验证收发和故障处理。 |
| ADC | ADC1/2、采样保持、校准、常规与注入组、模拟看门狗、双 ADC、触发与 DMA，以及 ADC1 的内部温度传感器和 VREFINT 通道。用已知输入或内部通道验证采样，分析采样率和误差。 |
| DMA | DMA1 的 7 个通道、请求映射、仲裁、地址递增、传输宽度、普通和循环模式、半传输/完成/错误。验证内存搬运、定时器触发 ADC 采样及串口传输，排查映射和缓冲区问题。 |
| I²C | I²C1/2，开漏与上拉、START/STOP、重复起始、ACK/NACK、主从、时钟拉伸、仲裁、SMBus 相关模式和勘误。用已知器件做寄存器读写，验证 NACK、超时与恢复。 |
| SPI | SPI1/2，主从、CPOL/CPHA、NSS、单线与双线、帧长、错误标志、CRC 与 DMA。用回环或外接器件验证，能识别采样边沿配置错误。 |
| bxCAN | 位时序、收发器、仲裁、过滤器、发送邮箱与接收 FIFO、错误状态。先做控制器回环，外部通信再用收发器与对端验收。 |
| USB FS Device | 48 MHz 时钟、枚举、端点、包缓冲区、控制传输与挂起/恢复。用 USB 设备实验检查枚举和数据交换。USB 和 bxCAN 共用专用缓冲区及两项中断向量，分别验证或分模式运行。 |
| IWDG 与 WWDG | 对照时钟来源、窗口限制、刷新时机和复位标志，故意触发超时、过早刷新等适用场景并确认复位原因。 |
| RTC、BKP、PWR | RTC 时钟、计数与报警、备份寄存器与防篡改、VDD/VDDA/VBAT、内部稳压器、Sleep/Stop/Standby、上电与掉电复位（POR/PDR）、PVD 和唤醒。验证 RTC 报警、重启后的数据保留和唤醒来源，记录板级供电条件。 |
| 存储与辅助单元 | Flash 擦写和保护、选项字节、SRAM、存储映射、启动模式、硬件 CRC 与 96 位 UID。用实验保留页验证擦写和掉电后读回，对比硬件和软件 CRC，记录算法参数。 |

**每个模块的交付标准**包括带出处的手册原图或时序图、适用模式和取舍、相关寄存器与位段速查、可重复的最小验证、一道可复现的故障或边界场景，以及课后题。有公开 SPL API 的模块列出函数并对照关键寄存器操作。内核功能用 CMSIS 对照，USB 用独立设备库对照。UID、启动引脚等条目按实际接口给出读取或观察方法。对需要外接器件的实验列出接线、器材、替代验证及其覆盖范围，保留真板外部通信的验收项。每批验收后更新清单的完成状态和实测证据。

## 项目与独立验收

1. **有步骤的入门项目**。用寄存器和 SPL 对照完成按键与 LED，故意漏开时钟并排查。接着完成按键切换 LED 模式，验证 EXTI 边沿与消抖。
2. **有验收条件的阶段项目**。做串口控制 PWM 调光和反应计时器，自行选定时器、算频率、处理非法输入并解释中断和主循环分工。再做周期采集项目，使用定时器触发 ADC、DMA 存入缓冲区、USART 输出数据。
3. **独立综合项目**。根据任务书做采集与记录终端。独立选择 I²C 或 SPI 器件，用 RTC 标记时间，通过串口或独立的 USB/CAN 模式交互，验证看门狗恢复。交付前提交模块和数据流图、引脚与资源分配表、上板测试及一次排故记录。验收覆盖正常运行、设备无响应和复位恢复，再独立完成一个需求变更，例如修改采样周期并证明丢失数据能被识别。其余模块的能力由各自实验验证。
4. **HAL 与 FreeRTOS**。全外设裸机路线通过后，先用 HAL 迁移已验收的项目并复用测试，再学习 FreeRTOS 的任务划分、队列、调度和中断到任务通信。

## 技术方案与约束

| 方案 | 取舍 |
| --- | --- |
| Markdown 手册与示例工程 | 起步快，适合验证教材。随着条目增多，搜索与交叉链接主要靠手工维护。 |
| Astro + Starlight 静态站 | 采用这套方案。复用导航、搜索和代码展示，能把课程、速查、题目和项目互链。需要先验证中文词和精确标识符的实际检索效果。 |
| 仿真或自动判分平台 | 可以增加即时反馈，工作量取决于外设支持和判分规则，放在裸机课程验证后的候选范围。 |

课程与项目用 Markdown，寄存器、位段、函数及题目出处用结构化内容管理。实现时可决定具体文件格式，页面生成后须能检索这些条目。第一阶段以本地静态站和已有编译、烧录流程为边界，支持折叠答案和人工勾验。账号、云进度和在线编译留到后续有实际需求时评估。

首个实验以按键和 LED 为基础，提供寄存器版和 SPL 版两份可独立编译的完整工程、构建说明和预期现象。板载 LED 引脚和有效电平要以实际板卡为准，课程给出可选接法。芯片型号已经确定，具体板卡接线和 IDE 留到实验工程阶段核实。选择并记录样章使用的 SPL 版本，标明手册章节及函数所在源码文件。交付时检查两份固件能构建，真板行为由使用者按清单验收。
