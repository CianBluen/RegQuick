# RCC + GPIO Implementation Plan

**Goal** 交付一个可在本地运行的中文学习站和两份按键控制 LED 的固件。

**Architecture** Astro + Starlight 提供课程、速查和项目导航。JSON 维护可检索的位段与 SPL 函数条目。两个 Keil 目标共用启动文件和时钟基线，各自编译一份独立的应用代码。

**Tech Stack** Astro 5、Starlight 0.37、Markdown、Keil MDK / ARMCC 5、STM32F10x SPL V3.5.0。

**Spec** `docs/superpowers/specs/2026-11-13-stm32-learning-design.md`。

## 全局约束

芯片为 STM32F103C8T6。运行与验收在本地。本批交付 RCC 外设时钟使能与 GPIO，后续课程按覆盖清单等待用户逐批验收。硬件验收由用户在自己的板上完成。

## 任务

- [x] 建立 `package.json`、`astro.config.mjs` 和 `src/content.config.ts`。创建首页、课程、速查、项目和全外设路线入口。执行 `npm run build` 检查静态输出和搜索索引。
- [x] 在 `src/data/gpio.json` 保存 GPIO 七个寄存器及位段、APB2 时钟门控和 SPL API。用 `src/components/Reference.astro` 渲染条目并建立稳定锚点。用本地生产预览验证 `RCC_APB2ENR`、`GPIO_Init`、`CNF13` 和“开漏”都可检索。
- [x] 用 `src/content/docs/learn/rcc-gpio.md` 讲解门控、输入、输出和排故，每个知识点配三道折叠题。核对 RM0008 第 7、9 章与 SPL 源码。公开面经题注明日期和原帖。
- [x] 在 `firmware/rcc-gpio` 下创建 Register 和 SPL 两个目标。约定 PA0 接低有效按键，PA1 接高有效外置 LED。两版从 HSI 启动，统一预期现象，分别用 ARMCC 构建并生成 HEX。提供故障变体及复位后检查门控位的步骤。
- [x] 用生产预览验证导航、搜索、答案折叠和课程跳转。核对固件产物和项目页验收清单，在 `README.md` 写明本地启动与真板步骤。
