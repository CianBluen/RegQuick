# 时钟、中断与调试实施计划

目标是从 RCC 寄存器推导工作频率，从 GPIO 电平追踪到异常处理函数，再用真板实验验证。

- [x] 时钟课用 RM0008 图 8 讲 HSI、HSE、PLL、AHB、APB、定时器倍频与其他分支。提供可切换的频率计算和寄存器速查。
- [x] 中断课用 RM0008 的 EXTI 框图和引脚映射讲输入选择、边沿、挂起、屏蔽和向量入口。用 SysTick 和 EXTI 演示优先级，附调试观察项。
- [x] 沿用 PA0 按键、PA1 LED 和 ARMCC，完成按键切换、非阻塞消抖、错选端口变体和软件触发入口。支持 HSI 8 MHz 与可选 HSE 8 MHz → PLL 72 MHz。
- [x] 检查示例编译、固件链接、站点构建、页面链接、搜索、练习折叠、频率计算和移动端。
- [ ] 使用者按项目页在真板确认时钟切换、按键消抖、错误端口及两种优先级序列。
