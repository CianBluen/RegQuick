适用于 STM32F103C8T6。GPIO 寄存器偏移相对各端口基址，RCC 寄存器偏移相对 RCC 基址。GPIO 寄存器按 32 位访问。`RW` 为可读写，`RO` 为只读，`WO` 为只写。

条目中的 C 片段可放进实验工程，使用已有的 STM32F10x 头文件。运行前先满足该示例说明的时钟、引脚配置和接线条件。

位段名称按端口的通用布局列出。实际能接到板上的引脚取决于 LQFP48 封装、时钟配置和板卡连线。 [中文数据手册引脚表](/manuals/stm32f103x8b-zh.pdf#page=17)

寄存器见 [中文参考手册 §6.3.7](/manuals/rm0008-zh.pdf#page=70) 和 [§8.2](/manuals/rm0008-zh.pdf#page=113)。函数见 [中文固件函数库手册 GPIO 章节](/manuals/spl-user-manual-zh.pdf#page=122)，实际读写核对 SPL V3.5.0 的 stm32f10x_gpio.c/.h 和 stm32f10x_rcc.c/.h。
